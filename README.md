# Mesh Viewer · 三维网格查看器

基于 three.js 的桌面级网页网格查看器，面向大規模三角/四边形网格的检视与索引拾取。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest 单元测试
npm run build      # 类型检查 + 产物构建（dist/）
npm run preview    # 预览构建产物
```

打开页面后：点击「打开…」或直接把 `.obj` / `.ply` 文件拖进视口。
`samples/` 目录提供测试模型（四边形立方体、纯线框、ascii/二进制 PLY）。

## 功能

- **多格式导入**：OBJ（含 `l` 显式边、负索引、任意多边形面）、PLY（ascii + binary LE/BE，vertex/face/edge 元素）；解析在 Web Worker 中进行，界面不卡顿；支持一次拖入/选择多个文件
- **多模型同屏**：遮挡关系正确；右侧模型列表逐模型控制 点/边/面 显隐、
  不透明度（α）与三成分颜色，可展开查看统计、一键移除
- **环境光照**：环境光 / 主光 / 补光强度滑杆 + 背景色，实时生效；头灯开关提供
  视线方向恒定补光
- **点 / 边 / 面任意组合显示**；纯线框或纯点云文件自动适配开关状态；
  无显式边的网格自动派生边界线框（四边形不产生对角线）
- **建模软件式检视**：双视角控制器 —— 球面（默认，任意角度无死锁旋转）/ 轨道
  （缩放到光标），工具栏或 `C` 键切换；右上角视向轴 Gizmo 点击 XYZ 手柄快速切换
  六向视角；可穿入模型内部观察；
  `F` 聚焦选中 · `Home` 全景 · `G` 网格地面 · `Esc` 取消选择
- **源索引拾取**（核心）：hover 实时预览，单击锁定选中，
  信息面板显示元素在**源文件中**的顶点 / 面 / 边索引及坐标、角点、长度等详情；
  四边形面拾取还原为原始四边形而非三角形；跨模型拾取全局最近命中
- **大规模性能**：50 万顶点量级流畅 —— BVH 加速面拾取、按模型缓存的空间哈希网格加速
  顶点/边拾取、每图层单次 draw call、Transferable 零拷贝回传

## 架构

设计文档见 [DESIGN.md](./DESIGN.md)。分层：

```
core/   中立数据模型（CSR 面结构）、拓扑、派生边 —— 无 three.js 依赖，可单测
io/     解析器注册表 + OBJ/PLY 解析器 + Worker 加载管线   ← 扩展点① 新格式
render/ 场景管理、相机（球面/轨道双控制器）、视向轴 Gizmo、ModelRegistry 多模型容器、
        三图层 MeshView、BVH/空间网格拾取、高亮                        ← 扩展点② 新图层
ui/     类型化事件总线、工具栏、模型列表、环境光照、选中面板、状态栏 ← 扩展点③ 条件显示等功能
```
