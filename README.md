# Mesh Viewer · 三维网格查看器

基于 three.js 的桌面级网页网格查看器，面向大規模三角/四边形网格的检视与索引拾取。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest 单元测试
npm run build      # 类型检查 + 产物构建（dist/）
npm run preview    # 预览构建产物
```

打开页面后：点击「打开…」或直接把 `.obj` / `.ply` 文件拖进视口。
`samples/` 目录提供测试模型（四边形立方体、纯线框、ascii/二进制 PLY）。

## 功能

- **双模式**：分析模式（拾取/诊断）与舞台模式（分组、变换 gizmo、自动排布、
  影棚/论文环境预设、阴影）经工具栏一键切换，相机位姿各自记忆
- **多格式导入**：OBJ（含 `l` 显式边、负索引、任意多边形面）、PLY（ascii + binary LE/BE，vertex/face/edge 元素）；解析在 Web Worker 中进行，界面不卡顿；支持一次拖入/选择多个文件，排队可取消
- **多模型同屏**：遮挡关系正确；右侧场景单元树逐模型控制 点/边/面 显隐、
  不透明度（α）与三成分颜色，可展开查看统计、勾选成组、一键移除
- **环境光照**：环境光 / 主光 / 补光强度滑杆 + 背景色，实时生效；头灯开关提供
  视线方向恒定补光
- **几何诊断可视化**：斑马条纹（反射线曲面检查）与曲率热力图（平均/高斯/主曲率，
  余切权离散估计在 Worker 中计算，彩虹/蓝白红双色图 + 多模型合并数值图例）
- **渲染图导出**：一键导出 PNG，支持 1×/2×/4× 超采样与透明背景
- **点 / 边 / 面任意组合显示**；纯线框或纯点云文件自动适配开关状态；
  无显式边的网格自动派生边界线框（四边形不产生对角线）
- **建模软件式检视**：三视角控制器 —— 弧球（默认，抓取跟随感强）/ 球面
  （任意角度无死锁旋转）/ 轨道（缩放到光标），工具栏或 `C` 键循环切换；右上角视向轴
  Gizmo 点击 XYZ 手柄快速切换六向视角；可穿入模型内部观察；侧栏可折叠
  `F` 聚焦选中 · `Home` 全景 · `G` 网格地面 · `Esc` 取消选择 · 舞台 `W/E/R` 切换变换
- **源索引拾取**（核心）：hover 实时预览，单击锁定选中，
  信息面板显示元素在**源文件中**的顶点 / 面 / 边索引及坐标、角点、长度等详情；
  四边形面拾取还原为原始四边形而非三角形；跨模型拾取全局最近命中
- **大规模性能**：50 万顶点量级流畅 —— BVH 在 Worker 中后台构建、
  按模型缓存的空间哈希网格加速顶点/边拾取、每图层单次 draw call、Transferable 零拷贝回传

## 架构

设计文档见 [DESIGN.md](./DESIGN.md)。分层：

```
core/   中立数据模型（CSR 面结构）、拓扑、曲率、派生边 —— 无 three.js 依赖，可单测
io/     解析器注册表 + OBJ/PLY 解析器 + Worker 加载/曲率管线  ← 扩展点① 新格式
render/ 场景管理、相机（轨道/球面/弧球三控制器）、视向轴 Gizmo、ModelRegistry 多模型容器、
        三图层 MeshView、BVH(Worker 构建)/空间网格拾取、高亮    ← 扩展点② 新图层
stage/  舞台模式：独立场景、TransformControls 编排、分组模型、自动排布
app/    装配层控制器：加载队列、诊断状态、交互分发
ui/     类型化事件总线、工具栏、场景单元树、环境光照、选中面板、状态栏 ← 扩展点③ 条件显示等功能
```
